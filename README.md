# CTF 乾坤袋

CTF 乾坤袋是一个浏览器端 CTF 工具箱，提供编码转换、密码学辅助、Web 数据处理、文件分析、隐写分析、取证、OSINT、PWN 与逆向等工具。

开源版只保留客户端工具，不包含登录、邀请码、积分、管理后台、数据库或付费服务。工具输入默认在浏览器本地处理，适合个人学习、比赛准备和授权安全测试。

## 功能

- 编码与文本转换
- 古典密码、哈希与密码学辅助
- Web 与网络数据处理
- 文件、二进制、图片、音频与隐写分析
- 取证、OSINT、PWN 与逆向辅助
- 工具搜索、分类浏览、收藏和最近使用
- 智能编解码
- 多步骤操作链
- 内置使用说明和工具手册

## 本地运行

需要 Node.js 20 或更高版本。

```bash
npm ci
npm run dev
```

打开 <http://127.0.0.1:5173/>。

## 构建与部署

```bash
npm run build
npm run preview
```

构建结果在 `dist/` 目录。把该目录交给 Nginx、GitHub Pages、Cloudflare Pages 或其他静态托管服务即可。

Nginx 需要为单页应用保留回退规则：

```nginx
location / {
    try_files $uri $uri/ /index.html;
}
```

仓库包含 GitHub Pages 工作流。推送到 `main` 后会自动构建并发布；仓库路径部署使用 `/ctf-qiankun/`，绑定自定义域名时使用根路径 `/`。

## 添加工具

工具代码位于 `client/src/tools/`，注册表位于 `client/src/tools/registry.ts`。新增工具时请：

1. 优先使用浏览器原生能力或已有依赖。
2. 默认不上传用户输入、文件和密钥。
3. 限制输入大小、文件大小和正则表达式复杂度。
4. 补充名称、分类、描述、关键词和示例输入。
5. 为错误输入提供清楚的提示。

## 安全边界

本项目只面向已获授权的学习、比赛和安全测试。请确认目标系统的授权范围，并遵守所在地法律法规。

开源版不提供服务端 API，也不会主动把工具输入发送到项目服务器。浏览器扩展、第三方脚本和部署者自行接入的服务可能改变这一边界，使用前请检查网络请求。
